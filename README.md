# 번역 테스트판 (1단계) - 음성인식 없이 번역 엔진만 테스트

이건 진짜 앱이 아니라 "실험용" 앱이에요.
목표는 딱 하나: **NLLB 번역 모델이 내 태블릿(갤럭시탭 S7+)에서 인터넷 없이도
실제로 잘 돌아가는지** 확인하는 거예요.

그래서 이 버전에는:
- ❌ 소리 듣기 (음성인식) 없음
- ❌ 화면 위에 뜨는 자막창 없음
- ✅ 일본어 문장을 손으로 입력하면 → 한국어로 번역해서 보여줌 (이것만 있어요)

이 테스트가 잘 되면, 다음 단계에서 "소리 듣기(위스퍼)"랑 "화면 자막창"을
합쳐서 진짜 쓰는 앱을 만들 거예요.

---

## 0단계. 전체 흐름 한눈에 보기

1. 이 폴더 전체를 깃허브(GitHub)에 올린다
2. 깃허브가 자동으로 컴파일해서 설치 파일(APK)을 만들어준다 (5분 정도 걸림)
3. 그 설치 파일을 태블릿으로 옮겨서 설치한다
4. 앱을 열고 번역 모델을 다운로드한다 (약 1GB, 와이파이 권장)
5. 일본어 문장을 넣고 '번역하기'를 눌러서 테스트한다

---

## 1단계. 깃허브에 코드 올리기

### 컴퓨터가 있다면 (드래그 앤 드롭만 하면 됨)

1. [github.com](https://github.com) 에 로그인
2. 오른쪽 위 `+` 버튼 → `New repository` 클릭
3. Repository name에 아무 이름이나 입력 (예: `nllb-translate-test`)
4. Public/Private 아무거나 선택하고 `Create repository` 클릭
5. 저장소가 생기면 `uploading an existing file` 이라는 파란 글씨 링크를 클릭
   (안 보이면 `Add file` → `Upload files` 버튼을 눌러도 돼요)
6. 이 프로젝트 폴더(`NllbTranslateTest`) **안에 있는 모든 파일과 폴더**를 통째로
   그 업로드 화면에 마우스로 끌어다 놓기 (드래그 앤 드롭)
   - `.github` 폴더도 반드시 같이 올려야 해요! (숨김 폴더처럼 보여도 꼭 포함)
7. 아래로 내려서 `Commit changes` 버튼 클릭

업로드가 끝나면 자동으로 빌드가 시작돼요 (다음 단계).

### 태블릿만 있다면

이전 앱(VideoSubTranslator) 때 알려드린 것처럼, 파일을 하나씩
"만들어서 붙여넣기"하는 방식을 쓰면 돼요. 파일 개수가 적어서 (10개 정도)
어렵지 않아요. 순서를 다시 안내해드릴 수 있으니 필요하면 말씀해주세요.

---

## 2단계. 자동으로 만들어진 설치 파일(APK) 받기

1. 저장소 페이지 상단 메뉴에서 `Actions` 탭 클릭
2. `Build APK` 라는 이름의 작업이 노란 점(진행 중) 또는 초록 체크(완료)로 떠 있을 거예요.
   완료될 때까지 3~5분 기다렸다가 그 항목을 클릭
3. 페이지 맨 아래 `Artifacts` 영역에 `app-debug-apk`가 보이면 클릭해서 다운로드
4. 다운로드된 zip 파일 안에 `app-debug.apk` 가 들어있어요. 태블릿으로 옮겨서 설치하세요.
   (설치 시 "출처를 알 수 없는 앱" 경고가 뜨면 허용해주세요 - 개인 테스트용이라 정상이에요)

---

## 3단계. 앱 사용법

1. 앱을 열면 "모델 상태: 아직 다운로드 안 됨" 이라고 나와요.
2. `번역 모델 다운로드` 버튼을 눌러요.
   - **와이파이 연결 상태에서 하는 걸 강력 추천해요** (약 1GB를 받아요)
   - 진행률이 화면에 표시돼요. 파일이 커서 몇 분 정도 걸릴 수 있어요.
3. 다운로드가 끝나면 자동으로 모델을 불러오고, "모델 상태: 준비 완료 ✅" 로 바뀌면서
   `번역하기` 버튼이 눌리게 돼요.
   - 한 번 다운로드해두면, 다음부터 앱을 켤 때는 다시 안 받아도 돼요 (자동으로 불러와요).
4. 입력창에 일본어 문장을 넣고 (예시 문장이 하나 미리 들어가 있어요) `번역하기`를 눌러요.
5. 아래에 한국어 번역 결과와 걸린 시간(밀리초)이 나와요.

여러 문장으로 테스트해보고 싶으면 입력창 내용을 지우고 다른 일본어 문장을 넣으면 돼요.

---

## 4단계. 저한테 알려주실 내용

테스트해보시고 아래 내용을 알려주시면 다음 단계 작업에 큰 도움이 돼요:

- 모델 다운로드가 잘 끝났는지 (에러가 나면 화면을 캡처해서 보내주세요)
- 번역 버튼을 눌렀을 때 정상적으로 결과가 나오는지, 아니면 에러 메시지가 뜨는지
  (에러가 뜨면 그 내용을 그대로 캡처해서 보내주세요 - 원인을 정확히 알 수 있어요)
- 번역 속도가 어느 정도인지 (화면에 나오는 "걸린 시간" 그대로 알려주시면 돼요)
- 번역 품질이 실제 사용감으로 어떤지 (여러 문장 테스트해보고 느낀 점)

---

## 참고: 이 테스트판이 하는 일 (간단 설명)

- 번역에 필요한 파일 3개(번역 엔진 2개 + 언어사전 1개, 총 약 1GB)를
  huggingface.co 라는 곳에서 앱이 첫 실행할 때 직접 받아와요.
- 한 번 받아두면 그 다음부터는 **인터넷 연결 없이도** 번역 자체는 동작해요
  (모델을 처음 받을 때만 인터넷이 필요해요).
- 번역 엔진은 메타(페이스북)에서 만든 NLLB라는 무료 오픈소스 모델이에요.
  구글 번역만큼 매끄럽진 않을 수 있지만, 완전 무료이고 사용 횟수 제한이 없어요.
